Smart Parking System in C

A beginner-friendly console-based parking management system built using the C programming language.

Features

- Add a car to the parking lot
- Remove a car from the parking lot
- Display total, occupied, and available spaces
- Prevent parking beyond the maximum capacity
- Prevent removing cars when the parking lot is empty
- Validate user menu input

Technologies

- C
- Standard Input/Output ("stdio.h")

How to Run

Compile with GCC:

gcc main.c -o parking

Run on Linux or macOS:

./parking

On Windows:

parking.exe

Concepts Practised

- Variables and arithmetic
- "if-else" conditions
- "do-while" loops
- "scanf()" input validation
- State management and boundary checking

Future Improvements

- Track individual parking spaces using arrays
- Store vehicle registration numbers
- Calculate parking fees
- Save records to a file
- Connect the logic to sensors in a future embedded systems project
